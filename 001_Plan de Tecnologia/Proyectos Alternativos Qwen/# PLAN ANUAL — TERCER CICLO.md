## 2. Objetivos anuales por grado

### 7.° grado
- Identificar componentes físicos y lógicos del computador, configurando el sistema operativo y archivos.
- Comprender los fundamentos de redes LAN/WAN y el protocolo básico de internet.
- Programar hardware físico (micro:bit) utilizando bloques en MakeCode y visualizando el código JavaScript.
- Escribir los primeros scripts en Python textual (variables, entrada/salida, hola mundo).

### 8.° grado
- Aplicar normas de seguridad informática, gestionando contraseñas y reconociendo amenazas (phishing, malware).
- Dominar las estructuras de control en Python (condicionales, bucles, listas).
- Entrenar modelos de Machine Learning básicos (clasificadores de texto/imagen) integrando datos reales.
- Utilizar IA generativa de manera supervisada, aplicando la Declaración de Uso Ético y verificando resultados.

### 9.° grado
- Comprender y aplicar la Ley N° 7593/2025 de Protección de Datos Personales en entornos digitales.
- Modularizar soluciones en Python mediante funciones y módulos.
- Diseñar, depurar y documentar un proyecto integrador en Python que resuelva un problema real.
- Evaluar la transición al Nivel Medio, comprendiendo los perfiles del BTI, BTC y BCB.

## 6. Metodología y recursos

### Metodología central
- **Transición bloque → código:** Se utiliza MakeCode para mostrar el código JavaScript/Python detrás de los bloques, reduciendo la fricción cognitiva al pasar a la sintaxis textual pura en Thonny/VS Code.
- **Aprendizaje basado en problemas (ABP):** Los scripts de Python no son ejercicios abstractos; resuelven problemas matemáticos, automatizan tareas o procesan datos reales.
- **IA como asistente auditado:** En 8.° y 9.°, se enseña a usar IA generativa para explicar errores o generar esqueletos de código, pero el estudiante debe comprender, depurar y validar cada línea.
- **Depuración sistemática:** Se enseña a leer los trazas de error (tracebacks) de Python y a usar `print()` de diagnóstico o el debugger de Thonny.

### Recursos necesarios

| Recurso | Estado | Observaciones |
|---|---|---|
| Sala de Informática — Secundaria | 25 PCs, 8 GB RAM | Adecuada para VS Code, Thonny y MakeCode |
| Python 3 + Thonny IDE | **Pendiente de instalación** | Acción inmediata requerida antes del inicio del año |
| micro:bit (v2) | **Pendiente de adquisición** | Se requieren 10-12 unidades (trabajos en tríos) |

| Conectividad | 150 Mbps | Suficiente para 25 usuarios simultáneos |

## 7. Evaluación

### Instrumentos de evaluación

| Instrumento | Lo que evalúa | Frecuencia |
|---|---|---|
| **Prueba de funcionamiento (Computación)** | Identificación de componentes, configuración de red, evaluación de seguridad y conocimiento de la Ley 7593/2025. | Semestral |
| **Entrega de script/proyecto (Programación)** | Código funcional, limpio, comentado. Uso correcto de estructuras de control y funciones. | Cada unidad |
| **Proyecto integrador de fin de año** | Aplicación completa (Python o micro:bit). Incluye documentación técnica y presentación oral. | 4.° Bimestre |
| **Declaración de Uso Ético de IA** | Evaluación de la honestidad académica y el criterio crítico al usar IA generativa (8.° y 9.°). | Cada entrega que use IA |
| **Rúbrica de proceso** | Autonomía, resolución de errores, trabajo colaborativo, seguimiento de normas de la sala. | Continua |

### Política de evaluación de IA (8.° y 9.°)
- Si un estudiante utiliza IA generativa y **no** adjunta la Declaración de Uso Ético, el trabajo se considera falta de integridad académica (nota cero), según el Reglamento Institucional.
- Si la adjunta, se evalúa la calidad de la verificación y el entendimiento del código/texto generado, no solo el resultado final.
