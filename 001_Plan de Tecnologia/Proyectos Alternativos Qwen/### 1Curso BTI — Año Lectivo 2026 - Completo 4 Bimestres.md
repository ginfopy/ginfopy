# ESTRUCTURA SEMANAL TIPO

Cada semana de clase se organiza en tres disciplinas complementarias del Gabinete más la disciplina de Algorítmica:

| Disciplina | Horas semanales | Enfoque |
|---|---|---|
| **Algorítmica** | 4 h | Pensamiento formal: lógica, matemática, algoritmos, pseudocódigo. |
| **Gabinete Laboratorio (Web)** | 4.5 h | Desarrollo web: HTML5, CSS3, JavaScript. |
| **Gabinete Software** | 2.25 h | Programación en Python, estructuras de datos, POO. |
| **Gabinete Hardware/Redes** | 2.25 h | Ensamblaje, mantenimiento, sistemas operativos, redes. |

Las cuatro disciplinas se retroalimentan: Algorítmica aporta la lógica formal; Gabinete Software la implementa en código; Gabinete Laboratorio la aplica a la web; Gabinete Hardware/Redes provee el sustrato físico donde todo corre.

# PRIMER BIMESTRE (9 semanas — 9 de febrero a 10 de abril de 2026)
**Objetivo general del bimestre:** Fundamentos de lógica simbólica y teoría de conjuntos. Primeros algoritmos en pseudocódigo y diagramas de flujo. Introducción a Python. Desarrollo web estático con HTML5 y CSS3. Reconocimiento y ensamblaje de hardware.

---

## SEMANAS 1-2 — Teoría de Conjuntos + HTML5 estructura + Componentes del PC

### Algorítmica (8 h)
**Contenido:** Introducción a la teoría de conjuntos. Concepto de conjunto, elemento, pertenencia. Conjuntos finitos e infinitos. Conjunto vacío, unitario, universal. Representación: extensión y comprensión. Subconjuntos. Diagramas de Venn. Operaciones: unión, intersección, diferencia, complemento. Leyes de álgebra de conjuntos.
**Actividades:** Ejercicios prácticos con diagramas de Venn. Resolución de problemas de conteo usando principios de conjuntos. Aplicación a casos reales (agrupamiento de datos).

### Gabinete Laboratorio (9 h)
**Contenido:** Introducción al desarrollo web. ¿Qué es HTML? Estructura de un documento HTML5. Etiquetas básicas: `<!DOCTYPE>`, `<html>`, `<head>`, `<body>`. Etiquetas semánticas: `<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`. Etiquetas de texto: `<h1>` a `<h6>`, `<p>`, `<strong>`, `<em>`, `<br>`, `<hr>`. Listas: `<ul>`, `<ol>`, `<li>`.
**Actividades:** Creación de la primera página web personal. Estructura semántica correcta. Validación con W3C Validator.

### Gabinete Software (4.5 h)
**Contenido:** Introducción al entorno de desarrollo. Instalación y configuración de Python 3 y Thonny IDE (si no está instalado). Primer script: "Hola mundo". Sintaxis básica: indentación, comentarios (`#`), función `print()`. Tipos de datos básicos: `int`, `float`, `str`, `bool`. Variables: declaración, asignación, nombres válidos.
**Actividades:** Escritura y ejecución de los primeros 5 scripts. Experimentación con tipos de datos. Uso de `type()` para verificar tipos.

### Gabinete Hardware (4.5 h)
**Contenido:** Componentes internos del PC: CPU (procesador), RAM, disco duro/SSD, motherboard (placa madre), fuente de poder, tarjeta de video, gabinete, coolers. Identificación visual de cada componente. Función de cada uno. Diferencias entre HDD y SSD. Generaciones de CPU y sockets.
**Actividades:** Apertura de PCs de la sala (con supervisión). Identificación física de cada componente. Elaboración de ficha técnica de una PC armada.

## SEMANAS 3-4 — Lógica simbólica + CSS3 básico + Python variables/E-S + Ensamblaje

### Algorítmica (8 h)
**Contenido:** Introducción a la lógica simbólica. Proposiciones y conectores lógicos: negación (¬), conjunción (∧), disyunción (∨), condicional (→), bicondicional (↔). Tablas de verdad. Tautologías, contradicciones y contingencias. Leyes de Morgan. Equivalencias lógicas. Aplicación a circuitos digitales (introducción conceptual).
**Actividades:** Construcción de tablas de verdad. Verificación de tautologías. Demostración de equivalencias usando leyes. Relación entre lógica y estructuras condicionales en programación.

### Gabinete Laboratorio (9 h)
**Contenido:** Introducción a CSS3. Selectores: de tipo, de clase (`.clase`), de ID (`#id`), descendentes, universales. Propiedades básicas: `color`, `background-color`, `font-family`, `font-size`, `margin`, `padding`, `border`. Box model: contenido, padding, border, margin. Unidades: px, em, rem, %.
**Actividades:** Estilizado de la página web personal. Aplicación de colores, tipografías y espaciado. Creación de una clase CSS reutilizable.

### Gabinete Software (4.5 h)
**Contenido:** Entrada y salida de datos: `input()` y `print()` con formato. Conversión de tipos: `int()`, `float()`, `str()`. Operadores aritméticos: `+`, `-`, `*`, `/`, `//`, `%`, `**`. Operadores de comparación: `==`, `!=`, `<`, `>`, `<=`, `>=`. Formateo de cadenas: f-strings.
**Actividades:** Scripts que piden datos al usuario y realizan cálculos: calculadora de IMC, conversor de monedas, calculadora de edad. Uso de f-strings para presentar resultados.

### Gabinete Hardware (4.5 h)
**Contenido:** Procedimiento de ensamblaje paso a paso. Precauciones de seguridad (electricidad estática, manipulación de componentes). Orden de ensamblaje: CPU en motherboard → RAM → motherboard en gabinete → fuente → discos → cables → tarjeta de video. Conexión de paneles frontales.
**Actividades:** Ensamblaje guiado de una PC completa en grupos de 4-5 estudiantes. Documentación fotográfica del proceso.

## SEMANAS 5-6 — Introducción a algoritmos + CSS3 intermedio + Python condicionales + Sistemas operativos

### Algorítmica (8 h)
**Contenido:** Concepto de algoritmo: definición, características (finitud, definición, entrada, salida, efectividad). Representación de algoritmos: lenguaje natural, pseudocódigo, diagramas de flujo. Símbolos de diagramas de flujo: inicio/fin, proceso, decisión, entrada/salida, conector. Estructuras de control secuenciales.
**Actividades:** Traducción de problemas simples a pseudocódigo y diagramas de flujo. Ejercicios de trazabilidad: seguir un algoritmo paso a paso y registrar los valores de las variables.

### Gabinete Laboratorio (9 h)
**Contenido:** CSS3 intermedio. Posicionamiento: `static`, `relative`, `absolute`, `fixed`. Display: `block`, `inline`, `inline-block`, `flex` (introducción). Flexbox básico: `display: flex`, `justify-content`, `align-items`, `flex-direction`. Imágenes: etiqueta `<img>`, atributos `src`, `alt`, `width`, `height`. Enlaces: etiqueta `<a>`, atributo `href`, enlaces internos y externos.
**Actividades:** Creación de una página web con galería de imágenes y navegación por anclas. Diseño de un menú horizontal con Flexbox.

### Gabinete Software (4.5 h)
**Contenido:** Estructuras condicionales en Python: `if`, `if-else`, `if-elif-else`. Operadores lógicos: `and`, `or`, `not`. Condicionales anidados. Evaluación de verdad en Python (truthy/falsy).
**Actividades:** Programas con toma de decisiones: verificador de mayoría de edad, clasificador de notas, calculadora con menú de opciones, validador de contraseñas básico.

### Gabinete Hardware (4.5 h)
**Contenido:** Sistemas operativos: concepto, funciones, tipos (Windows, Linux, macOS). Instalación de Windows 10/11: creación de USB booteable con Rufus/Media Creation Tool, proceso de instalación, particionado de disco. Configuración post-instalación: actualizaciones, drivers, software básico.
**Actividades:** Instalación guiada de Windows 10/11 en una máquina virtual (VirtualBox) o en PC física dedicada. Configuración inicial: usuario, región, actualizaciones.

### Gabinete Hardware/Redes (4.5 h)

**Actividades:** Identificación de la topología de la red del aula. Elaboración de diagrama de red. Configuración básica de una red LAN entre 2 PCs con cable cruzado o switch.

## SEMANAS 24-25 — Introducción a POO + JavaScript proyecto + POO Python + Evaluación Hardware

### Algorítmica (8 h)
**Contenido:** Introducción a la Programación Orientada a Objetos (POO): concepto de objeto, clase, atributos, métodos. Diferencia entre POO y programación estructurada. Notación UML básica para clases.
**Actividades:** Modelado de problemas del mundo real con clases: clase `Persona`, `Vehiculo`, `CuentaBancaria`. Diagramas UML.

**Actividades:** Implementación de las clases modeladas en Algorítmica. Creación de objetos, llamada a métodos, modificación de atributos.

### Gabinete Hardware/Redes (4.5 h)

## Política de uso de IA

Todo trabajo que utilice IA generativa (GitHub Copilot, ChatGPT, Claude, etc.) debe incluir la **Declaración de Uso Ético de la IA** que especifique:
1. Herramienta utilizada.
2. Propósito del uso (generar ideas, explicar conceptos, revisar código, etc.).
3. Método de verificación del resultado (cómo el estudiante validó que el código es correcto).

La ausencia de esta declaración se considera falta de integridad académica. El estudiante debe ser capaz de explicar y defender cada línea de código, incluso si fue generada con asistencia de IA.
